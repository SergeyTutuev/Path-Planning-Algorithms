# Path-Planning-Algorithms

Коллекция алгоритмов планирования пути, реализованных с использованием симулятора **IR-SIM** — легковесной среды на Python для навигации, управления и обучения с подкреплением[reference:0].

Репозиторий содержит примеры интеграции различных планировщиков (A*, JPS, RRT, RRT*, Informed RRT*, PRM) в сценарии IR-SIM, а также вспомогательные скрипты для визуализации и настройки миров.

## 🚀 Возможности

- **Единый workflow** для всех планировщиков: построение карты, создание планировщика, поиск пути, визуализация / следование[reference:1].
- Поддержка **сеточных** (grid-based) и **сэмплированных** (sampling-based) алгоритмов.
- Готовые примеры на Python для быстрого прототипирования.
- Конфигурация сценариев через YAML-файлы (например, `waypoint_world.yaml`).
- Вспомогательные скрипты для наложения траекторий и анализа результатов (`plot_overplay.py`).

## 🧭 Поддерживаемые алгоритмы

| Планировщик | Импорт из `irsim.lib.path_planners` | Тип | Когда использовать |
|-------------|--------------------------------------|-----|---------------------|
| **A*** | `AStarPlanner` | Сеточный (8-связный) | Быстрый и оптимальный путь на сетке |
| **JPS** | `JPSPlanner` | Сеточный (оптимизированный A*) | Те же пути, что у A*, но быстрее на открытых сетках |
| **RRT** | `RRT` | Сэмплированный | Несеточные препятствия (Shapely); допустимый, но не оптимальный путь |
| **RRT*** | `RRTStar` | Сэмплированный | Более короткие оптимизированные пути за счёт переподключения |
| **Informed RRT*** | `InformedRRTStar` | Сэмплированный | Более быстрая сходимость к оптимуму после первого решения |
| **PRM** | `PRMPlanner` | Сэмплированный (roadmap) | Множественные запросы на одной статической карте |

> Сеточные планировщики (A*, JPS) и PRM работают сOccupancy Grid из `obstacle_map`; RRT / RRT* / Informed RRT* могут использовать как сетку, так и геометрию Shapely[reference:2].

## ⚙️ Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/SergeyTutuev/Path-Planning-Algorithms.git
   cd Path-Planning-Algorithms
   ```
2. **Установите зависимости:**
   ```bash
   pip install numpy matplotlib
   ```
## Быстрый старт: запустите пример с Informed RRT*
  ```bash
  python IR-sim_example.py
  ```
